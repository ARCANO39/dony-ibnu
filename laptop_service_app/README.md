# Sistem Manajemen Service Laptop & Inventaris Sparepart

Aplikasi Flutter + Supabase lengkap dengan skema database PostgreSQL, manajemen stok otomatis via trigger database, serta portal publik tracking pelanggan.

## Cara Penggunaan:
1. Ekstrak file zip ini.
2. Jalankan perintah `flutter pub get`.
3. Masukkan URL dan Anon Key Supabase Anda di `lib/main.dart`.
4. Eksekusi skrip `supabase/schema.sql` di SQL Editor Supabase Anda.
5. Jalankan `flutter run`.
